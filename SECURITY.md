# Security policy

## Reporting a vulnerability

Do not disclose an unpatched vulnerability, credentials, pairing codes, device
addresses, or captured content in a public issue.

Use **Report a vulnerability** on this repository's GitHub **Security** tab. If
private vulnerability reporting is unavailable, open a public issue containing
only a request for private maintainer contact and no vulnerability details.

Include the affected SceneGlowHA version, Home Assistant version, device
platform, impact, and the minimum reproduction information needed to investigate.

General bugs and feature requests can use the public issue tracker.
